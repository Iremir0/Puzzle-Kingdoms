# assets/

Art and audio only, no scripts. Every third-party file must be listed in
CREDITS.md before it is committed.

- `characters/` 3D unit models (.glb) and portraits
- `environments/` battlefield, backgrounds
- `ui/` icons, gem sprites, frames
- `audio/` sfx and music (.ogg)
- `effects/` particles, VFX textures

File names: `snake_case`, prefixed by type when helpful (`gem_warrior.png`).
