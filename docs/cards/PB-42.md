# PB-42 Chapter 3: Troll Marsh

Owner: Emir · Milestone: M8 · Size: L · Branch: `feature/PB-42-chapter-3` · From: the 2026-11-21 review (content)

## Why
After 2-10 the game ends. Ten more stages add about forty minutes and use the new enemies of PB-41 and tier 2
enemies, which no stage uses yet.

## Build
1. Ten stages 3-1 to 3-10 made with the generator of PB-40 and tuned with its bot, one lesson each, the last
   a boss stage. Obstacles and goals from Chapter 2 come back mixed.
2. Chapter map entry (title, node positions), one tutorial prompt per new enemy.
3. Rewards in line with Chapter 2 (gold rises, three more star chests).

## Done when
- [x] Ten stage assets in the campaign, each with a measured win rate in the target band
- [x] Data tests pass (every stage loads, unit ids, map positions)
- [x] GDD Chapter 3 table with the measured numbers

## Notes
_Findings, numbers, decisions taken while working on this card._

**2026-11-21 (Emir).** The plan is `Tools/Balance/Plans/chapter3.json` (one blueprint per stage: required enemies,
pool, size, tier 2 count, moves, goal, covers, band, map position, prompts). `dotnet run -c Release --project
Tools/Balance -- 150 --generate Tools/Balance/Plans/chapter3.json` tries 6 seeds a stage, tunes each, keeps the one in
the band with the win time nearest 28 s (24 s for 3-8, 32 s for 3-10), writes `Stage_3_N.asset` with a guid made from
the stage id (so a rerun keeps every reference) and adds missing stages to the campaign. Same plan, same stages.
First pass: 3-2 (ice), 3-3 and 3-7 (stones) missed their goal 27-31% of the time and 3-4 stayed too easy even at 6x
HP; more moves, one more stone, a tier 2 Berserker and a higher search limit fixed them. Table in GDD. Map title
"Chapter 3: Troll Marsh"; the map has no painting yet (`Map_Chapter3` sprite) and the arena uses Chapter 2's.
Not done: play each stage by hand, a phone run, the Chapter 3 map painting and enemy models (owner).
