# PB-31 Cloud save, Google Play Games

Owner: — · Milestone: M8 · Size: M · Branch: `feature/PB-31-cloud-save` ·
Wave: 3 (D-045) · Needs: Play Console app (PB-17)

## Why
Players change phones; losing a kingdom and twenty stages loses the player. Signing in
with Google Play Games keeps the save in the cloud.

## Today
- Save is JSON with a version, written crash-safe
  ([ProfileStore](../../Assets/_Project/Scripts/Flow/ProfileStore.cs),
  [SafeFile](../../Assets/_Project/Scripts/Flow/SafeFile.cs), D-039, PB-14).

## Build
1. **Logic:** conflict rule — compare two profiles (progress first, then time); the player
   chooses when both have progress the other lacks. Tests.
2. **Google Play Games plugin** (CREDITS.md first): sign-in, saved games read / write.
3. **Flow:** load local, then cloud; on conflict show the choice; write both after each save.
4. **Views:** sign-in in Settings, the conflict dialog.
5. Sign-in stays optional: playing without it works as today.

Import the Google Play Games plugin (*Assets → Import Package*), then
*Window → Google Play Games → Setup → Android setup* with the ids from Play Console.

## Not in this card
