# PB-25 Daily Challenge

Owner: — · Milestone: M8 · Size: M · Branch: `feature/PB-25-daily-challenge` ·
Wave: 3 (D-045) · Needs: PB-19 (stage goals); online part: decision on a backend

## Why
Our combat is deterministic, so the same seed gives everyone the same board and the
same enemy, and results are truly comparable (GDD §3, §10 post-MVP item 3). No
competitor can offer a fair daily ranking this simply.

## Today
- Everything random goes through a seed ([SeededRandom](../../Assets/_Project/Scripts/Logic/Core/SeededRandom.cs)),
  and battles replay from armies + rules + Rally ticks.
- A stage is an asset; there is no generated stage yet.

## Build
1. **Logic:** `DailyChallenge.For(date)` → a stage built from the date's seed (enemy
   set and formation from a pool, stones, goal) and a board seed; same date, same
   challenge on every device. Score = remaining army HP % then time. Tests: same date
   gives the same stage, different dates differ, score ordering.
2. **One attempt a day**, best result and history saved in the profile.
3. **Local first:** the screen shows today's challenge, your result and your last 7 days.
4. **Online (after the backend decision):** submit date + input log; the server can
   re-run the battle to check the score; top 50 + your rank.
5. **Views:** challenge card on the map, result screen with the rank.
