# Audio

- `Music/`: music tracks (streamed, stereo). Map, puzzle, battle, results.
- `Sfx/`: short sound effects (mono, decoded on load).
- `Placeholder/`: the generated stand-ins (D-036) until real files replace them.

Put new files in the right folder first, then drag them into `Data/SoundBank.asset`. Write each file in `CREDITS.md`
before you commit it. The whole method is in `docs/AUDIO.md`.
